# deltaRPC
> [!WARNING]
> This program is on development. Except few amounts of bugs.

A lightweight, zero-modification Discord Rich Presence bridge for [DELTARUNE](https://deltarune.com).

## Features
- **Mod-Friendly** | Compatible with bunch of mods that removes, adds, modifies, improves, feature.
- **No Modding Required** | Just launch program with DELTARUNE. that's it.
- **Lightweight** | Its lightweight (wow!)

## Supported OS

| OS | Supported | Notes |
|:---|:---:|:---|
| **Linux** | ✅ | Native support |
| **Windows** | ⚠️ | Experimental Support |
| **macOS** | ❌ | Planned |

## Requirements
- PC with Linux, Windows or Mac
- Discord *desktop* client running
- Steam version of DELTARUNE
